FAQ

Frequently asked questions and known issues.

macOS says the app is damaged or cannot be opened

Termlo is not signed by Apple yet. On first launch, right-click Termlo in Applications › Open, then confirm. If macOS still refuses:

xattr -dr com.apple.quarantine /Applications/Termlo.app

Linux: “version GLIBC_… not found”

Published builds require Ubuntu 20.04 / Debian 11 (glibc 2.31) or newer.

Linux: Quake mode does not work

The global hotkey uses libkeybinder-3.0:

sudo apt install libkeybinder-3.0-0

On Wayland, some desktops do not allow global hotkeys.

Linux: “Access denied” on a serial port

Add your user to the dialout group, then log back in (see Serial port).

Can I import my Windows Terminal theme?

Yes: Settings › Apparence (appearance), import button. Termlo accepts a single theme, a list of themes or Windows Terminal’s settings.json directly (schemes section).

Where is my data?

Profiles, settings, history and vault live in a local database, in the app’s data folder. Nothing is sent online: Termlo only contacts the servers you connect to.

Is the interface available in English?

Not yet: the interface is in French.
