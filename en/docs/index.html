Getting started

Install Termlo, open your first terminal and tour the interface.

Installation

SystemFileNotes
WindowsTermlo-Setup-x.y.z.exeWindows 10 or newer. Per-user install, no admin rights needed.
macOSTermlo-x.y.z.dmgmacOS 12 or newer. Drag Termlo to Applications. The app is not signed: on first launch, right-click › Open.
LinuxTermlo-x.y.z-linux-x64.tar.gzUbuntu 20.04 / Debian 11 or newer. Extract the archive, then run termlo. Quake mode needs libkeybinder-3.0.

The interface is in French for now.

First launch

Termlo detects your system shells and creates a profile for each one:

  • Windows: PowerShell, PowerShell 7 (pwsh) if installed, cmd, Git Bash and your WSL distributions;
  • macOS and Linux: your default shell ($SHELL, started as a login shell) and those listed in /etc/shells.

A first tab opens with the default profile. When you quit, the layout of tabs and panes is saved and restored on the next start (this can be turned off in Settings).

The interface

  • Tab bar: it is also the title bar. + opens a tab with the default profile, the ▾ arrow another profile, the bolt an SSH quick connect. Double-click a tab to rename it, drag it to move it.
  • Panes: split the tab right (Ctrl+Shift+D) or down (Ctrl+Shift+E), move between panes with Alt+arrow, resize with Ctrl+Shift+arrow.
  • Special screens: Profiles, Identities and Settings open in tabs, as in Tabby.
  • Command palette: Ctrl+Shift+P (⌘P on macOS) gives access to everything, with fuzzy search.

Closing without losing work

Closing a tab, a pane or the window while a process is still running (vim, ssh, a build…) asks for confirmation. When a shell exits, its exit code is shown: Enter restarts it, Esc closes the pane.
