Profiles

Local shells, SSH connections and serial ports, organized in groups.

The profile manager

Open it from the tab bar’s ▾ arrow › Gérer les profils… (Manage profiles), or from the palette. The list is grouped and searchable. + creates a local shell, SSH or serial port profile.

Each profile has a name, a group, an icon and a color, used by its tabs. One of them is the default profile, opened by + and Ctrl+Shift+T.

Local shell

  • executable and arguments (for example pwsh.exe -NoLogo, bash --login -i);
  • working directory (your home folder by default);
  • environment variables, one per line (NAME=value);
  • shell integration, on by default: it enables history and suggestions (see Suggestions and highlighting).

Profiles detected at startup are kept up to date automatically. An uninstalled shell stays in the list, marked as missing.

Importing ~/.ssh/config

The manager’s Importer ~/.ssh/config button turns your ~/.ssh/config hosts into profiles (Host, HostName, User, Port, IdentityFile, ProxyJump). A preview shows the profiles that will be created in the “~/.ssh/config” group.

Deleting a profile

Deleting asks for confirmation. Tabs already open with that profile stay open.
