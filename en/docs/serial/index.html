Serial port

Talk to a board, a router or network equipment.

Creating a serial profile

In the profile manager, + › Port série (serial port):

  • port: list of detected ports, with their description (refresh button);
  • baud rate: common values (9600, 115200…) or any value;
  • data bits, stop bits, parity, flow control (none, XON/XOFF, RTS/CTS);
  • Enter key: sends CR, LF or CR+LF;
  • local echo, for devices that do not echo what you type.

Unplugging

Removing the cable during a session shows “Port … disconnected” without crashing Termlo; the Reconnect banner reopens the port once it is plugged back in.

Linux: permissions

Serial port access requires the dialout group:

sudo usermod -aG dialout $USER

then log out and back in.
