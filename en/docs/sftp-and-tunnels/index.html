SFTP and tunnels

Browse server files and forward ports from an SSH session.

The SFTP panel

On a connected SSH pane, Ctrl+Shift+S (⌘S on macOS) or the folder icon opens the side panel. Its Files tab uses the same connection as the terminal:

  • navigation (parent folder, editable path, refresh), name, size, date and permission columns;
  • upload: the upload button or drag and drop from your file manager;
  • download, new folder, rename, copy path, change permissions (octal, e.g. 755);
  • deleting and overwriting an existing file always ask for confirmation.

Transfers show their progress and speed, and can be cancelled.

Tunnels

The panel’s Tunnels tab forwards ports through the SSH connection:

  • Local (-L): a port on your machine leads to a host and port as seen from the server (for example a database that only listens on the server);
  • Remote (-R): a port on the server leads to your machine.

A tunnel saved in the profile can start automatically when connecting. A local port already in use or a forward refused by the server shows a clear message.
