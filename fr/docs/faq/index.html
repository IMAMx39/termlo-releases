FAQ

Questions fréquentes et problèmes connus.

macOS dit que l’application est endommagée ou ne peut pas être ouverte

Termlo n’est pas encore signé par Apple. Au premier lancement, faites un clic droit sur Termlo dans Applications › Ouvrir, puis confirmez. Si macOS refuse toujours :

xattr -dr com.apple.quarantine /Applications/Termlo.app

Linux : « version GLIBC_… not found »

Les versions publiées demandent Ubuntu 20.04 / Debian 11 (glibc 2.31) ou plus récent.

Linux : le mode Quake ne fonctionne pas

Le raccourci global utilise libkeybinder-3.0 :

sudo apt install libkeybinder-3.0-0

Sous Wayland, certains environnements ne permettent pas les raccourcis globaux.

Linux : « Accès refusé » sur un port série

Ajoutez votre utilisateur au groupe dialout, puis reconnectez-vous (voir Port série).

Mon thème Windows Terminal peut-il être importé ?

Oui : Paramètres › Apparence, bouton d’import. Termlo accepte un thème seul, une liste de thèmes ou directement le settings.json de Windows Terminal (section schemes).

Où sont mes données ?

Profils, paramètres, historique et vault sont dans une base locale, dans le dossier de données de l’application. Rien n’est envoyé en ligne : Termlo ne contacte que les serveurs auxquels vous vous connectez.

L’interface est-elle disponible en anglais ?

Pas encore : l’interface est en français.
