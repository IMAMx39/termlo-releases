Bien démarrer

Installer Termlo, ouvrir un premier terminal et faire le tour de l'interface.

Installation

Premier lancement

Termlo détecte les shells de votre système et crée un profil pour chacun :

  • Windows : PowerShell, PowerShell 7 (pwsh) s’il est installé, cmd, Git Bash et vos distributions WSL ;
  • macOS et Linux : votre shell par défaut ($SHELL, lancé en shell de connexion) et ceux de /etc/shells.

Un premier onglet s’ouvre avec le profil par défaut. À la fermeture, la disposition des onglets et des panneaux est enregistrée et restaurée au démarrage suivant (désactivable dans les Paramètres).

L’interface

  • Barre d’onglets : elle sert aussi de barre de titre. Le + ouvre un onglet avec le profil par défaut, la flèche ▾ un autre profil, l’éclair une connexion rapide SSH. Double-cliquez sur un onglet pour le renommer, glissez-le pour le déplacer.
  • Panneaux : divisez l’onglet à droite (Ctrl+Shift+D) ou en bas (Ctrl+Shift+E), passez d’un panneau à l’autre avec Alt+flèche, redimensionnez avec Ctrl+Shift+flèche.
  • Écrans spéciaux : Profils, Identités et Paramètres s’ouvrent dans des onglets, comme dans Tabby.
  • Palette de commandes : Ctrl+Shift+P (⌘P sur macOS) donne accès à tout, avec une recherche floue.

Fermer sans perdre son travail

Fermer un onglet, un panneau ou la fenêtre alors qu’un processus tourne encore (un vim, un ssh, une compilation…) demande une confirmation. Quand un shell se termine, son code de sortie s’affiche : Entrée le relance, Échap ferme le panneau.
