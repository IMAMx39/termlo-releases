Port série

Dialoguer avec une carte, un routeur ou un équipement réseau.

Créer un profil série

Dans le gestionnaire de profils, + › Port série :

  • port : liste des ports détectés, avec leur description (bouton de rafraîchissement) ;
  • vitesse : valeurs courantes (9600, 115200…) ou valeur libre ;
  • bits de données, bits de stop, parité, contrôle de flux (aucun, XON/XOFF, RTS/CTS) ;
  • touche Entrée : envoie CR, LF ou CR+LF ;
  • écho local, pour les équipements qui ne renvoient pas ce que vous tapez.

Débranchement

Retirer le câble pendant une session affiche « Port … déconnecté » sans faire planter Termlo ; le bandeau Reconnecter rouvre le port une fois rebranché.

Linux : droits d’accès

L’accès aux ports série demande le groupe dialout :

sudo usermod -aG dialout $USER

puis fermez votre session et reconnectez-vous.
