SFTP et tunnels

Parcourir les fichiers du serveur et rediriger des ports, depuis une session SSH.

Le panneau SFTP

Sur un panneau SSH connecté, Ctrl+Shift+S (⌘S sur macOS) ou l’icône de dossier ouvre le panneau latéral. Son onglet Fichiers utilise la même connexion que le terminal :

  • navigation (dossier parent, chemin éditable, rafraîchir), colonnes nom, taille, date et droits ;
  • envoyer : bouton « Envoyer des fichiers… » ou glisser-déposer depuis l’explorateur ;
  • télécharger, nouveau dossier, renommer, copier le chemin, changer les droits (octal, ex. 755) ;
  • supprimer et remplacer un fichier existant demandent toujours une confirmation.

Les transferts s’affichent avec leur progression et leur débit, et peuvent être annulés.

Tunnels

L’onglet Tunnels du panneau redirige des ports à travers la connexion SSH :

  • Local (-L) : un port de votre machine mène à un hôte et un port vus depuis le serveur (par exemple une base de données qui n’écoute que sur le serveur) ;
  • Distant (-R) : un port du serveur mène à votre machine.

Un tunnel enregistré dans le profil peut démarrer automatiquement à la connexion. Un port local déjà pris ou une redirection refusée par le serveur affichent un message clair.
